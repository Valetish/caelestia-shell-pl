# Polish localization for Caelestia Shell

This development fork adds a complete Polish interface to Caelestia Shell. It
contains 840 translated messages covering Nexus settings, the dashboard,
launcher, taskbar, sidebar, lock screen, and notifications generated by
Caelestia itself.

> [!IMPORTANT]
> This project tracks Caelestia's current development branch. Its translation
> framework is newer than the latest stable release, so keep your existing
> package or configuration available before testing this version.

## What is translated

- Nexus settings and all settings pages;
- dashboard, weather forecast, and performance information;
- launcher and its built-in actions;
- network, Bluetooth, audio, and VPN controls;
- notification panel, lock screen, and Caelestia messages;
- all three Polish plural forms.

Notification content sent by other applications remains in the language used
by that application. Caelestia cannot safely translate messages originating
from a browser, messenger, or email client.

## Test installation on Arch Linux

Install the dependencies listed in the main README, then build and install the
fork in the same way as the official source version:

```bash
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/
cmake --build build
sudo cmake --install build
```

After restarting Caelestia, open:

**Settings → Language and region → Interface language → polski**

You can also set the language manually in
`~/.config/caelestia/shell.json`:

```json
{
  "general": {
    "language": "pl"
  }
}
```

Removing the `language` property restores automatic detection from the system
locale.

## Translation checks

```bash
fish scripts/trs.fish raw
msgcmp --use-fuzzy plugin/src/Caelestia/I18n/trs/pl.po plugin/src/Caelestia/I18n/trs/raw.pot
fish scripts/trs.fish compile pl /tmp/caelestia-pl.mo
python3 scripts/trs-check.py --strict
```

The repository also includes a GitHub Actions workflow that validates catalog
completeness, placeholder formatting, and successful compilation.

## Project direction

The primary goal is to refine the Polish localization and contribute it back
to the official Caelestia project. Additional languages can be added as
separate PO catalogs, for example `uk.po` for Ukrainian.
