# Polish localization for Caelestia Shell

This development fork adds a complete Polish interface to Caelestia Shell. It
contains over 800 translated messages covering Nexus settings, the dashboard,
launcher, taskbar, sidebar, lock screen, and notifications generated by
Caelestia itself.

> [!IMPORTANT]
> This project tracks Caelestia's current development branch. Its translation
> framework is newer than the latest stable release, so keep your existing
> package or configuration available before testing this version.

## What is translated

- Nexus settings and all settings pages;
- dashboard, weather forecast, and performance information;
- launcher and its built-in actions;
- network, Bluetooth, audio, and VPN controls;
- notification panel, lock screen, and Caelestia messages;
- all three Polish plural forms.

Notification content sent by other applications remains in the language used
by that application. Caelestia cannot safely translate messages originating
from a browser, messenger, or email client.

## Safe test on Arch Linux

The following method does not use `sudo`, replace the official installation,
or touch `~/.config/caelestia`. Source code, libraries, and test settings are
kept under a separate directory. Install the dependencies from the main README,
then run:

```bash
mkdir -p "$HOME/.local/src"
git clone --branch main https://github.com/Valetish/caelestia-shell-pl.git \
  "$HOME/.local/src/caelestia-shell-pl"
cd "$HOME/.local/src/caelestia-shell-pl"
```

Build and install the test version for the current user only:

```bash
CAELESTIA_PL_TEST_ROOT="$HOME/.local/share/caelestia-pl-test"
cmake -B build-test -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$CAELESTIA_PL_TEST_ROOT"
cmake --build build-test
cmake --install build-test
```

Start it with an isolated configuration. The process stays attached to the
terminal; pressing `Ctrl+C` stops the test shell.

```bash
XDG_CONFIG_HOME="$CAELESTIA_PL_TEST_ROOT/config" \
CAELESTIA_LIB_DIR="$CAELESTIA_PL_TEST_ROOT/lib/caelestia" \
QML2_IMPORT_PATH="$CAELESTIA_PL_TEST_ROOT/lib/qt6/qml${QML2_IMPORT_PATH:+:$QML2_IMPORT_PATH}" \
qs -p "$CAELESTIA_PL_TEST_ROOT/etc/xdg/quickshell/caelestia"
```

Then open:

**Settings → Language and region → Interface language → polski**

During this test, settings are stored in
`~/.local/share/caelestia-pl-test/config/caelestia/shell.json`, not in the
regular configuration. You can set the language there manually if needed:

```json
{
  "general": {
    "language": "pl"
  }
}
```

Removing the `language` property restores automatic detection from the system
locale.

### System-wide installation

The standard `sudo cmake --install build` replaces system Caelestia files. Use
it only after a successful isolated test and keep a way to reinstall the
official package. The installation itself does not overwrite
`~/.config/caelestia/shell.json`, although backing that file up before a system
change is still recommended.

## Translation checks

```bash
fish scripts/trs.fish raw
msgcmp --use-fuzzy plugin/src/Caelestia/I18n/trs/pl.po plugin/src/Caelestia/I18n/trs/raw.pot
fish scripts/trs.fish compile pl /tmp/caelestia-pl.mo
python3 scripts/trs-check.py --strict
```

The repository also includes a GitHub Actions workflow that validates catalog
completeness, placeholder formatting, and successful compilation.

## Project direction

The primary goal is to refine the Polish localization and contribute it back
to the official Caelestia project. Additional languages can be added as
separate PO catalogs, for example `uk.po` for Ukrainian.
